# YouTube第3回 Aパート（台本・撮影設計、未収録）

**動画テーマ：** 写真からConv → BatchNorm → SiLU → CSPまでを、数値で追跡する。

| 場面 | 画面 | ナレーションの焦点 |
|---|---|---|
| 00:00-00:30 | セルフィー入力 | 「CNNは何を見ている？」疑問を提示 |
| 00:30-02:00 | 48×32 RGBと選択位置 | 画素値とチャネルの意味 |
| 02:00-04:30 | Conv 27項、コマ送り | 3×3×3から1つの出力値を作る |
| 04:30-06:30 | BN、γ/βスライダー | 正規化と学習モード、評価モードの違い |
| 06:30-08:00 | SiLUとReLU | 非線形性が何を変えるか |
| 08:00-10:30 | CSPのMain/Bypass/Residual/Concat | 分岐しているが同じ位置の特徴量を扱う |
| 10:30-12:00 | NumPy実装課題 | Web教材の出力と手元のコードを比較 |

**制作条件：** 動画に使用する特徴マップの値はWeb実験室の計算値と一致させる。映像は記録・編集前であり、現時点で公開済みとは表記しない。

CHAPTER 01

画像とは、数値の配列である

CNNは「人物」や「猫」を画像として眺めているわけではありません。最初に渡されるのは、各画素に格納された数値の配列です。

カラー画像の1画素は一般にR（赤）、G（緑）、B（青）の3値で表せます。8bit画像なら各値は0〜255です。この教材では計算前に255で割り、0〜1の浮動小数点値へ変換します。

pixel = (R, G, B) = (180, 120, 90)
normalized = (180/255, 120/255, 90/255)
shape (表示用) = [H, W, C]

PyTorchのConv2dは通常、バッチ次元を含む[N, C, H, W]を使います。表示用の[H, W, C]とは次元の並び順が異なります。

本教材は元画像を48×32へ縮小して説明します。実際のYOLOXの入力解像度が48×32という意味ではありません。

CHAPTER 02

畳み込みは何を計算しているのか？

出力1値は、入力画像の小さな領域とKernelの重みを掛け合わせ、全て足すことで生まれます。

3×3のKernelと1チャネル入力を考えます。ある出力位置を(ox, oy)、strideをs、paddingをpとすると、Kernel内の位置(kx, ky)が読む入力位置は (ox·s + kx − p, oy·s + ky − p) です。

Y[oy,ox] = Σ(ky=0..2) Σ(kx=0..2)
  X_pad[oy*s + ky, ox*s + kx] * K[ky,kx]

PyTorchのConv2dは数学で厳密にいう畳み込み（Kernel反転あり）ではなく、相互相関（cross-correlation）を計算します。ここではPyTorchに合わせ、Kernelを反転しません。

padding=1なら周辺に0を追加してから計算します。画像の端では0埋めの項が生じます。SobelなどのKernelでは負の出力も自然に生じます。

CHAPTER 03

特徴マップはどう生まれる？

1箇所の積和が終わったら、同じKernelを次の出力位置で使用します。この処理を空間全体に繰り返すと、出力値が格子状に並びます。

3×3 Kernel、padding=1、stride=1、入力48×32なら出力も48×32です。隣接する出力位置は重複する入力領域を参照します。入力を48×32個の独立した領域に切り分ける処理ではありません。

W_out = floor((W + 2p - K_w)/s) + 1
H_out = floor((H + 2p - K_h)/s) + 1

W=48, H=32, p=1, K=3, s=1
=> W_out=48, H_out=32

特徴マップの「1マス」は出力値を格納する座標です。実際に参照した入力領域（受容野）は、その1マスより大きくなり得ます。

CHAPTER 04

なぜ特徴マップにはチャネルがあるのか？

1つのKernelセットから1つの出力チャネルができます。出力チャネルを3つ作りたければ、通常は3種類のKernelセットを用意します。入力がC_inチャネル、出力がC_outチャネルの場合、通常の畳み込み重みの形は [C_out, C_in, K_h, K_w] です。

input:     [C_in, H, W]
weights:   [C_out, C_in, K_h, K_w]
output:    [C_out, H_out, W_out]

現在の教材では説明のため、ぼかし・Sobel X・Sobel Yという固定Kernelで3つの特徴マップを作ります。実際のYOLOXでは、モデルの重みは学習で決まります。

CHAPTER 05

複数の特徴マップは次層へどう渡る？

次の層の各出力チャネルは、入力側の全チャネルから重み付き和を集めます。前層のマップを独立に送って終わるわけではありません。

Y[o,oy,ox] = b[o] + Σ(c,ky,kx)
   W[o,c,ky,kx] * X[c,oy*s+ky-p,ox*s+kx-p]

Strideが2の場合、出力の座標が2つずつ進みます。本教材の入力48×32・Kernel3×3・padding1なら、次層の幅は24、高さは16です。

3D表示の「板」はチャネルを視覚化したものです。CNNが入力画像を物理的な3次元空間へ押し出して計算しているわけではありません。

CHAPTER 06

NumPyでスクラッチ実装する

ここからは完成済みの畳み込み関数を使わず、上の数式をPythonで再現します。最初に出力形状、次にpadding、次に1チャネルの2D計算、最後に複数入力・出力チャネルへ拡張します。

for oy in range(out_h):
    for ox in range(out_w):
        patch = padded[oy*s : oy*s+k, ox*s : ox*s+k]
        out[oy, ox] = np.sum(patch * kernel)

REFERENCE & LIMITATIONS

何が実物で、何が教育用の簡略化か

この教材はCNNの積和計算を理解するための小規模なモデルです。48×32の入力、固定Kernel、3入力→2出力の次層は教育用です。公式YOLOXのBackbone・PAFPN・SimOTA・BBox予測を再現していません。

可視化の色は見やすいようにスケーリングしていますが、計算は生の数値で行っています。RGB→明るさはsRGB上の近似式であり、厳密な線形光度変換ではありません。

学習内容が進むと、特徴マップの格子からBBoxが予測される仕組み、極小頭部でのIoUの感度、さらにSigned LTRBのような新方式を独立に設計する演習へ接続していきます。

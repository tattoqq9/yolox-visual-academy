UNIT 03-B / OFFICIAL TOPOLOGY

YOLOX-NanoのBackboneを実装できるようになるまで

Unit 03-Aでは小さな固定重みのCNNでConv・BN・SiLU・CSPの概念を学びました。ここでは、公式YOLOX-Nano（2021年公開設定）に対応する本格的なPyTorchネットワークへ進みます。**教科書を読む前と読んだ後**に、同じセルフィー画像から計算されたテンソルを実験室で観察してください。

この教科書と対応する実験

Focus → dark2 → dark3 → dark4 → dark5 を3Dで回転し、実際の出力値、CSPの分岐、Depthwiseのパラメータ数を確認します。

Unit 03-Bの操作型教材へ
最重要：本教材に同梱したテンソルの意味

公開版の数値は、公式アーキテクチャに対応したモデルをPyTorchでforwardした結果です。ただし、**重みは固定seedでランダム初期化されており、学習済みモデルではありません**。数値・shape・チャネル演算の確認には使えますが、「このチャネルが顔を学習した」などとは解釈できません。学習済み公式チェックポイントを安全に取得した場合は、後述のexporterで別のtraceを作れます。

1. Nanoの設定を正しく読む

公式 yolox_nano.py は depth=0.33、width=0.25、depthwise=True、基本入力416×416です。これは画像サイズのスケールではなく、ネットワーク内での層数とチャネル幅を調節する設定です。

本教材の80クラスモデル

モデル全体の学習パラメータ数：912,159個（約0.91M）。内訳はBackbone 459,968、PAFPN 347,424、Head 104,767です。学習用の頭部1クラスモデルでは、Headの最後の分類層が異なるため、総数が変わります。

2. Focusからdark5までのテンソルを予測する

YOLOXのテンソル形状は [N,C,H,W]（バッチ・チャネル・高さ・幅）の順序です。416×416画像1枚の場合、次の値になります。

これらは公式 CSPDarknet に相当する構成で得られる値です。dark3・dark4・dark5は**Backboneの中間特徴**です。最終的に検出に使うP3/P4/P5は、これらをPAFPNで統合した後の特徴です。PAFPN自体の視覚化はUnit 03-Cで扱います。

実験：Focus～dark5を順番に選ぶ。各段階で空間サイズが半分になり、チャネルが2倍になることを確認してください。

3. Focusは何をしているのか

Focusは入力の偶数行・奇数行と偶数列・奇数列の組合せから、4組の位置情報をチャネル方向へ並べ替えます。**空間を間引いて情報を捨てる操作ではなく、位置をチャネルへ再配置する操作**です。

# [1, 3, 416, 416] → [1, 12, 208, 208]
patch_tl = x[..., ::2, ::2]
patch_bl = x[..., 1::2, ::2]
patch_tr = x[..., ::2, 1::2]
patch_br = x[..., 1::2, 1::2]
x = torch.cat((patch_tl,patch_bl,patch_tr,patch_br), dim=1)
# 12入力チャネル → 3×3 Conv → 16出力チャネル

Focusの後にBatchNormとSiLUを伴う3×3 Convが続きます。入力の空間次元が半分となるのはFocusの再配置によるものです。

4. Depthwise Separable Convのパラメータ数

通常のStandard Convはすべての入力チャネルと出力チャネルをK×Kで結びます。Depthwiseはまず入力チャネルごとに独立したK×Kを行い、Pointwise 1×1でチャネルを混合します。

StandardConv weights = C_in * C_out * K * K
Depthwise+Pointwise weights = C_in * K * K + C_in * C_out

例：入力64ch、出力64ch、3×3ならStandardは 36,864 個、Depthwise+Pointwiseは 4,672 個の重みです（BatchNormのγ・βを含みません）。

注意：公式のDWConvはDepthwise、Pointwiseの両方でBNとSiLUを使います。BN学習パラメータを含む場合は別途数えます。演算量の削減率は、出力の空間サイズにも依存します。

5. CSPが「2分岐」と呼ばれる理由

YOLOXのCSPLayerは、単に入力テンソルを2つにスライスして再結合する構造ではありません。入力から**別々の1×1 Convで2本の枝を作り**、一方をBottleneck群へ通し、もう一方とConcatしてから最後の1×1 Convで出力へ変換します。

# YOLOXのCSPLayer概念（module名は公式に対応）
a = self.m(self.conv1(x))
b = self.conv2(x)
y = torch.cat((a, b), dim=1)
return self.conv3(y)

たとえばdark3のCSPは、64入力ch → 32ch + 32ch → Concatで64ch → 最終64chとなります。中間Bottleneckは3回です。Concat後も同じ値が保持されるとは限らず、最後のConvによって各チャネルの情報が混合されます。

6. 本当に「実際のYOLOX」を表示していると言えるか？

重要なのは、図とPyTorchの計算が同一であることです。今回のtraceは各StageへのForward Hookで取得し、JSONに保存したチャネルの数値をブラウザで表示します。3D板は表示方法であり、特徴テンソルそのものはPyTorchから取得しています。**未学習の特徴は、意味のある物体特徴をまだ獲得していません。**

実モデルの学習済み特徴を見たい場合

公式のYOLOX-Nano 80クラス用チェックポイントを本人のWSLで取得し、リポジトリ内の tools/unit03b/export_trace.py に --weights を与えます。学習済みを確認した場合は --checkpoint-status verified-pretrained を指定できます。指定しなければ学習状態未確認と表示します。重みの出所・互換性を検証し、権利確認なしに生成物や重みを公開しないでください。公開版のtraceを書き換えず、まず別パスへ出力して比較することを推奨します。

7. スクラッチ実装演習

学生用PyTorchスターターを取得して、Focus、DWConv、CSPLayerの一部を実装してください。出力形状・パラメータ数・チャネルの結合順序が検証対象です。

問1：Focusの4組がどの順序で並ぶか説明できる？

416×416×3が208×208×12になる理由と、位置にある画素値が消えていないことを数値で確認してください。

問2：groups=C_in とすると各Kernelは何を受け取る？

Standard、Depthwise、Pointwiseで、入力と重みの次元をそれぞれ書き出してください。

問3：dark3のCSPでConcatする直前・直後の形は？

2本の1×1 Convの出力チャネル数を予測し、Concatで変わる次元を答えてください。

問4：暗い画像や小さい頭部では深い層で何が起こる？

空間解像度の低下、受容野、表現能力を分けて考えてください。まだ「このチャネルが頭部を認識した」とは断定しないこと。

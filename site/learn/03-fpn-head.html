01. なぜBackboneの後にPAFPNが必要なのか

物体検出では、小さな対象の位置を調べるために高解像度特徴が役立つ一方、深いネットワークで得られる広い受容野や抽象的特徴も利用したい。そこでYOLOXは、Backboneの複数スケールの特徴をPAFPNで統合します。

YOLOX-Nano（幅倍率0.25・入力416×416）のBackbone出力は以下の通りです。表記はPyTorchの [N,C,H,W] です。

入力特徴Shape累積Stride
dark3[1,64,52,52]8
dark4[1,128,26,26]16
dark5[1,256,13,13]32

ここで重要なのは、「各特徴マップは、入力画像を単純に独立タイルへ分割したものではない」という点です。各セルは周囲の画素から計算された値であり、受容野・格子の違いはUnit 02で詳しく扱いました。

02. Top-down：小さい特徴を拡大して結合

高解像度のP3を得るため、dark5から順にUpsample（最近傍補間）とConcat（チャネル連結）を行います。以下はNano構成での正確な途中Shapeです。

演算入力出力
lateral_conv0dark5 = 256×13×13128×13×13
Upsample ×2128×13×13128×26×26
Concat dark4128 + 128ch256×26×26
C3_p4256×26×26128×26×26
reduce_conv1128×26×2664×26×26
Upsample ×264×26×2664×52×52
Concat dark364 + 64ch128×52×52
C3_p3128×52×52**P3: 64×52×52**

Upsampleの計算

y[c, 2i + a, 2j + b] = x[c, i, j] for a,b ∈ {0,1}
※ 高さ・幅2倍、チャネル数不変、学習パラメータ0

Nearest-neighborでは入力1セルの値が出力の2×2マスへ複製されます。補間は、新しい意味を学習する演算ではありません。数値を実験室の「up0」「up1」ノードで比較できます。

Concatの計算

z = torch.cat([a, b], dim=1) a: [1,128,26,26] b: [1,128,26,26] z: [1,256,26,26]
※ z[:,0:128] = a / z[:,128:256] = b

Concatは加算ではなく「チャネルを並べる」演算です。したがって同じH×Wが必要です。値がどちらの入力から来たか、結合境界のチャネル127と128を選んで確認してください。

03. Bottom-up：高解像度からもう一度戻る

Top-downのP3を得ただけでは終了しません。YOLOPAFPNはP3から再び低解像度側へ進み、中間特徴と連結するBottom-up経路を持ちます。

演算入力出力
bu_conv2P3 64×52×5264×26×26
Concat reduce_conv164+64ch128×26×26
C3_n3128×26×26**P4: 128×26×26**
bu_conv1P4 128×26×26128×13×13
Concat lateral_conv0128+128ch256×13×13
C3_n4256×13×13**P5: 256×13×13**

ここではstride=2のDepthwise Separable Convで空間解像度を下げます。ConcatとC3が続くことで、Top-downで得た中間特徴が再統合されます。

dark3 / dark4 / dark5 はBackboneの出力です。PAFPNから出る P3 / P4 / P5 とは値も処理段階も異なります。同じ52×52でも dark3 と P3 は同一ではありません。

04. Decoupled Head：分類と回帰を分離

P3・P4・P5にそれぞれ独立した予測Headを適用します。YOLOX-NanoではStemの1×1 Convで各段階を64チャネルへ揃え、Classification枝とRegression枝へ分かれます。

P3: [1, 64,52,52] → Stem [1,64,52,52] P4: [1,128,26,26] → Stem [1,64,26,26] P5: [1,256,13,13] → Stem [1,64,13,13] Classification branch: Conv3×3 → Conv3×3 → 1×1 predictor (80ch) Regression branch: Conv3×3 → Conv3×3 → 1×1 predictor (4ch) └ 1×1 predictor (1ch objectness) Concatenate [BBox4, Obj1, Class80] → 85ch

ClassとBBoxが別の畳み込み系列を持つ理由は、クラス判別と位置回帰が異なる最適化目的を持つためです。ObjectnessはRegression枝の中間特徴から出力されます。図で単なる3本の完全独立枝と描いてしまうと、実際の共有関係と異なるため注意が必要です。

1つのグリッド位置から出力される85値は、[tx, ty, tw, th, obj_raw, class_0_raw, ..., class_79_raw] です。rawの先頭4値はBBoxを直接画素座標で表したものではありません。

出力階層Head raw Shapeグリッド数
P3[1,85,52,52]2,704
P4[1,85,26,26]676
P5[1,85,13,13]169
grid positions = 52² + 26² + 13² = 3,549 values per position (80 classes) = 4 + 1 + 80 = 85 raw scalars per image = 3,549 × 85 = 301,665

もし頭部1クラスに変更すれば計算上は 4+1+1=6 値/位置になります。ただし、公開トレース自体は80クラスのPyTorchモデルから生成しており、1クラスで再forwardしたデータではありません。

05. raw logitsと最終的なBBoxを区別する

今回のトレースはHeadの raw です。元のYOLOX推論では、ObjectnessとClass logitsにはsigmoidを適用し、BBoxには格子座標とstrideを利用したDecodeを適用します。説明のための概念式は以下です。

P(object) = sigmoid(obj_raw) P(class_k) = sigmoid(cls_raw[k]) cx = (grid_x + tx) × stride cy = (grid_y + ty) × stride w = exp(tw) × stride h = exp(th) × stride

sigmoidは0〜1の数値に変換しますが、未学習重みのスコアを「本当に頭部である確率」と解釈してはいけません。さらにBBoxを最終検出結果として採用するにはScore計算とNMSなどの後処理が必要です。そこはUnit 04で扱います。

参照モデルはObjectness・Class予測のbiasを事前確率0.01相当に初期化しています。raw値がおよそ-4.595、sigmoid後がおよそ0.01になるのは初期化の結果であって、モデルが学習済みである証拠でも、失敗している証拠でもありません。

06. 実テンソルの可視化と研究データの境界

公開シミュレータで使用するデータは、同じセルフィー画像を416×416へレターボックスした後、固定seedで初期化したPyTorchモデルに投入して取得したものです。FocusからHeadまでの各テンソルの一部チャネルを数値配列として保存しています。

画像の前処理は、縦横比を維持した縮小、左上配置、RGB値114のPadding、BGR順float32（0〜255）で行います。ここではPillow Bilinearを使用しており、公式デモのOpenCVとの間で画素値が若干異なる場合があります。

ブラウザの3D画面は、実数値をチャネルごとに色へ変換して重ねたものです。色の正規化は表示専用で、元テンソルを再計算しません。非表示のチャネルもPyTorchモデル内部に存在しますが、Web配布サイズを抑えるため一部のみ保存しています。

未学習の特徴に「このチャネルは頭部の輪郭を学習した」などと意味づけしないでください。学習済み重みで同じ図を作成する際には、出所・ライセンス・チェックポイントのhash・前処理・評価条件を確認してください。

07. PyTorchスクラッチ実装演習

学生用の未完成コードを埋め、Upsample・Concat・PAFPNの2経路、Headのraw出力とshapeを自力で再現します。教師用の完了コードは公開ZIPに含めません。

import torch

# [1,128,13,13] → [1,128,26,26]
upsampled = torch.nn.functional.interpolate(x, scale_factor=2,
                                           mode='nearest')
# [1,128,26,26] + [1,128,26,26]
fused = torch.cat([upsampled, dark4], dim=1)
assert fused.shape == (1,256,26,26)

実装課題では、単にShapeが一致すればよいわけではありません。Concatのチャネル順序、Upsampleで参照した入力位置、Headのraw順序と枝の共有関係を正しく再現してください。

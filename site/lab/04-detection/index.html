IoU（Intersection over Union）

IoU = 重なり面積 ÷ (面積A + 面積B − 重なり面積)

03 / SIMOTA

教師BBoxは、どの格子を「正例」にするのか。

YOLOXのGeometry Constraint → Cost → Dynamic K → 重複解消を再現。クラス2種・予測BBoxは全て演習用の人工値です。

SimOTAの教科書 →
幾何候補と最終正例◯ 候補中心 / ◎ 最終正例
GT A / class 0GT B / class 1

現行公式ソースの get_geometry_constraint() 型（半径1.5×stride）を採用。旧版で異なる候補抽出が存在するため、公式ソース参照と版の確認が必要です。

gridCenter = (gridIndex + 0.5) × stride
候補範囲 = |center − GT center| < 1.5 × stride
cost = BCE(√(sigmoid(cls)·sigmoid(obj)), onehot)
　　　 + 3 · (−ln(IoU + 1e−8)) + geometry penalty
dynamic K = max(1, int(sum(top10 IoU)))

候補フィルタは「全GTの中心範囲の和集合」。各GTに対する無効候補には大きなペナルティを与えます。Dynamic Kの競合は最小costのGTへ解消します。

04 / LOSS & GRADIENTS

損失が下がる方向を、微分で確かめる。

1正例＋1負例の小さな教材用バッチ。学習済みモデルの損失でも実際の訓練でもありません。 分母の正例数を1に固定した観察用の例です。

Lossと勾配の教科書 →
横方向の誤差と5×IoU Loss横軸：pxのズレ

曲線は単純な矩形・重なりの数学的シミュレーション。中央の×は現在のズレです。実際のネットワークの重みパラメータの勾配ではありません。

LogitとLossを動かす

Liou = 1 − IoU²
Lobj = BCEWithLogits(obj, 1) + BCEWithLogits(negObj, 0)
Lcls = BCEWithLogits(cls, IoU_target)
L = 5·Liou + Lobj + Lcls
d BCE(z,t) / dz = sigmoid(z) − t

YOLOXは分類のIoU品質ターゲットを割当時に作成し、勾配を止めて使用します。この例でもBBox方向の偏微分には5×IoU Lossだけを使います。分類・Objectnessのraw logitは別の独立変数です。
